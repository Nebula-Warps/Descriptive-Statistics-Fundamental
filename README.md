# Descriptive Statistics Fundamentals

This repository contains a Python implementation of core descriptive statistics formulas. The goal of this project is to build a deep, foundational understanding of data analysis by implementing the mathematical logic manually, without relying on external libraries like `numpy` or `statistics`.

## Tech Stack
*   **Language:** Python 3

## What This Code Does
Using a raw dataset of student scores, the script calculates:
*   **Median:** Sorts the data and finds the middle value, handling both even and odd numbered datasets.
*   **Mode:** Uses a custom nested loop to find the most frequent values, supporting multiple modes.
*   **Midrange:** Calculates the average of the maximum and minimum values.
*   **Average (Mean):** Sums the data and divides by the total count.
*   **Range:** Subtracts the minimum value from the maximum value.
